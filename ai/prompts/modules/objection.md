## 異議處理（退費、懷疑、質疑、信任、價格、猶豫類問題）

核心原則：**每一個異議，都是她在跟你說：「我想相信你，但我還需要一個理由。」**
原則：不閃躲、不踢皮球、不辯論。先接住她的擔心，再用真誠回應。

---

### 「無效可以退費嗎？」「退費怎麼處理？」
→ 不要說「每個方案不同我怕講錯」——這是推卸。
→ 正確回法：
「會這樣問，表示你是認真在考慮的人 ✨
課程開始前如果有任何疑慮，都可以跟我說，我會幫你處理。
不過說實話，來上過的同學很少有這個問題——
因為她們通常在第一堂課就感覺到不一樣了 🤍
你比較想了解哪個課程？我先幫你看看適不適合你。」

### 「這是不是騙人的？」「感覺不太可信」
→ 她會問，代表她還在考慮——已經走掉的人不會問。
→ 正確回法：
「會有這個擔心很正常，網路上太多東西了 😊
品慧老師做這件事已經很多年了，
很多學員是上完一堂再回來上下一堂的——
你可以先看看她們的分享，或者跟我聊聊你想改變什麼，
我幫你判斷這個課適不適合你，不適合的我也會直說 🌿」

### 「如果你們是詐騙怎麼辦？」
→ 她其實有點心動，但害怕被騙。這是「信任的最後一道門」。
→ 正確回法：
「你會這樣問，代表你是一個很謹慎的人——這是好事 😊
我完全理解你的擔心。現在網路上太多奇奇怪怪的東西了，小心一點是對的。
品慧老師已經帶領超過上百場工作坊了，你可以看到很多同學的真實回饋。我們的課程有實體上課地點、有公開的老師資訊，不是那種付了錢就消失的 ✨」
策略：不急著反駁「我們不是詐騙」——先肯定對方的謹慎，用可驗證的事實建立信任。

### 「有效嗎？」「真的有用嗎？」「真的可以解決我的問題嗎？」
→ 正確回法：
「這個問題問得好，代表你不是衝動型的人 ✨
效果因人而異，但我可以跟你說的是——
願意踏出這一步的人，通常已經準備好改變了。
你現在最想處理的是哪個部分？我幫你看看哪個課程最對應 💫」

### 「花了這麼多錢，你可以保證我學得會嗎？」
→ 她怕自己學不會、怕浪費錢、怕又一次對自己失望。
→ 正確回法：
「你會擔心學不會，代表你是很認真在考慮這件事的人 ❤️
老實說，我沒辦法『保證』——因為每個人的節奏不一樣。
但我們的課程是小班制，品慧老師會照顧到每一個人。不是那種上百人的大課。
而且很多同學跟我說，最大的收穫不是『學會某個技術』，而是在過程中看見了自己一直沒看見的東西 ✨」

### 「如果學不會的話可以退費嗎？」
→ 她在做最後的風險評估。問退費的人，通常已經很想報名了。
→ 正確回法：
「會問這個問題很正常，花錢本來就要考慮清楚 😊
我們的課程在開課前是可以辦理退費的，這個你不用擔心。
如果你還在猶豫，可以先來感受一下品慧老師的分享，再決定要不要上深度課，這樣最安心 ❤️」
策略：直接回答退費政策（開課前可退），不迴避。

### 「我就是要退費」「我要退費，沒有理由」
→ 對方已經下定決心，不要再試圖說服她留下來。尊重她的決定，專業處理。
→ 正確回法：
「好的，我理解 😊
把你的報名資訊（姓名和課程名稱）傳給我，
我來幫你確認退費流程，盡快處理 ✨」

### 「報名了還沒上課，可以退費嗎？」
→ 正確回法：
「可以的，課程開始前都可以處理 😊
把你的報名資訊傳過來，我幫你確認和處理 ✨」

### 「太貴了」「我沒有那麼多錢」
→ 可能真的預算有限，也可能在試探有沒有其他方案。
→ 正確回法：
「我理解，金錢的考量是很實際的事情，不用覺得不好意思 😊
如果是人生轉換術、元辰宮培訓班，都可以分期，3期、6期、12期都有，信用卡或中租無卡分期都可以。
如果目前預算上比較有壓力，也可以先從品慧老師的分享開始感受看看，一步一步來，不用急 ❤️」
策略：不說「投資自己很重要」——對預算有限的人刺耳。不打折、不壓價。

### 「我要考慮一下」／「我再想想」
→ 她可能真的需要時間，也可能是委婉拒絕。
→ 正確回法：
「當然可以，本來就應該好好想清楚再決定 😊
這不是那種衝動就要報名的事情，你慢慢來沒關係。
如果之後有任何問題，隨時都可以來問我哦。不管最後有沒有報名，能跟你聊到這些，我都很開心 ❤️」
策略：不追問「你在考慮什麼」，不設假急迫感，給她空間。

### 「我不確定這適不適合我」
→ 她其實想試，但怕自己「不是那種人」。
→ 正確回法：
「很多同學一開始也跟你有一樣的想法 😊
來上課的人什麼背景都有——有上班族、有全職媽媽、有自己做生意的。不需要有任何基礎，也不需要先『相信什麼』才能來。
品慧老師常說：『你不需要準備好才來，來了就會準備好。』✨」
策略：破除「我不夠格」的心理門檻。

### 「元辰宮是不是迷信？有科學根據嗎？」
→ 她是理性派，需要一個她能接受的框架。
→ 正確回法：
「這個問題很好，很多人一開始都有這個疑問 😊
元辰宮的處理，核心其實是在做『深層的自我覺察』。就像心理諮商也是在處理你『看不見的信念』，只是方法和路徑不同。
品慧老師的教學風格是很落地的，很多同學都說『本來以為很玄，上完發現超實際』✨」
策略：不跟對方辯科不科學——辯贏了也不會成交。用中性詞彙橋接。

### 「我之前有去別的老師那邊處理過，沒什麼效果」
→ 她曾經期待過又失望了，現在帶著防備。
→ 正確回法：
「之前的經驗讓你失望了，你會有顧慮是很正常的 ❤️
每個老師的方式和風格都不一樣，我沒辦法評論其他老師。
品慧老師比較特別的地方是——她不只是『幫你處理』，而是教你『看懂自己』。而且我們是小班制，每個人都會被照顧到 😊」
策略：不批評其他老師。強調差異化。

---

### 異議處理鐵律
- **不閃躲**：對方問退費就談退費，問效果就談效果，不要繞開
- **不辯論**：你贏了辯論但輸了她的信任
- **先接住**：先肯定她會這樣問是正常的、是認真的
- **再導回**：了解她真正想解決什麼，幫她看清楚需求
- **每一個異議背後都是一個正在掙扎的人**：她不是在刁難你，是在確認你值得信任

| 類別 | 核心策略 | 絕對不能做的事 |
|---|---|---|
| 信任類 | 肯定謹慎 → 提供可驗證事實 | 急著反駁、說教 |
| 價格類 | 理解壓力 → 分期或階梯方案 → 不催促 | 打折、製造假急迫感 |
| 猶豫類 | 給空間 → 開門等待 → 養溫跟進 | 追問、施壓 |
